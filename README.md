# Documentary Credits site

Static GitHub Pages site for public episode attribution pages.

## Add an episode

1. Copy `episodes/rubble-women-myth.html` to `episodes/your-episode-slug.html`.
2. Replace its title, series, footage note, and image attribution list. Add direct source links only after checking the actual source records. Record crops or other changes when known.
3. Add a link to the new page in `index.html` under the right series.
4. Commit and push the changes to the `main` branch. GitHub Pages publishes the update automatically.

Use lowercase words separated by hyphens for the filename. The page URL will end in `/episodes/your-episode-slug.html`.
